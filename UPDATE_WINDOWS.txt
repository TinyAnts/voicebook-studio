VOICEBOOK STUDIO - UPDATE YOUR EXISTING APP

1. Stop any conversion and close the app terminal window.
2. Extract this ZIP somewhere temporary.
3. Open the extracted VoicebookStudio folder. Copy everything inside it.
4. Paste those files into your EXISTING VoicebookStudio app folder.
   Choose "Replace the files in the destination" when Windows asks.
   Keep audiobooks and every .venv-* folder. Do not delete the existing folder.
   Do not put a second VoicebookStudio folder inside the first.
5. Double-click start.bat in the existing folder. If the old page is still open,
   press Ctrl+F5 after restarting to reload the new theme.

No reinstall is required. The first time you use a library narrator, the app
downloads the Qwen 1.7B voice-cloning model once (about 4.5 GB). "Create a new
narrator" downloads Qwen VoiceDesign once (about 4.5 GB). Nothing else changes.

OPTIONAL - FISH S2 PRO (4-bit) ENGINE
  Needs Docker Desktop (GPU enabled). Double-click install-fish.bat once
  (downloads ~5 GB model + builds a Docker image, 20-40 minutes). Then pick
  "Speech engine: Fish S2 Pro" and a library narrator. stop-fish.bat frees the GPU.

OPTIONAL - EVEN FASTER QWEN (CUDA graphs)
  Double-click install-qwen-fast.bat once (downloads ~3 GB of PyTorch into a new
  .venv-qwenfast folder; the Qwen voice model itself is NOT downloaded again).
  Restart start.bat. "Auto" then uses the fast engine and falls back to the batched
  engine automatically if it fails on your PC.

WHAT IS NEW (speed + bug fixes)
- Qwen narrates several passages at once on the GPU ("Batched GPU"), sized to your
  8 GB card automatically. If VRAM runs out it halves the batch and keeps going
  instead of crashing or silently spilling into slow shared memory.
- Optional CUDA-graph fast engine (install-qwen-fast.bat), with automatic fallback.
- New "GPU speed" panel (section 3): choose the engine and passages per batch.
- The monitor now shows "Narration speed" (x real time), the engine and batch size.
- WAV files are written on a background thread so the GPU never waits for the disk.
- Runaway passages are capped (the model default allowed 11 minutes of audio for one
  passage, which could stall a whole run).
- Changing the chapter selection no longer re-narrates text you already generated:
  identical passages from earlier runs of the same book and voice are copied over.
  This also works for the folders you already have.
- "Create missing voice samples" loads the model once for all voices.
- Cleared number boxes (page range, seed) no longer cause errors.
- Quieter activity log (repeated pad_token_id and symlink warnings removed). The SoX and
  flash-attn notices that remain are harmless.
- If PyTorch cannot see the GPU, the monitor now says so clearly.

Your existing books, audio and narration cache stay in audiobooks.
Keep the terminal open while converting. Refreshing the browser is fine.
